# ui-design-craft

An Agent Skill for visual UI craft — typography, spacing, optical alignment, icon and button geometry, dark-mode surfaces, sidebars, tables, shadows, and corner radius.

Use when designing, implementing, or reviewing how an interface looks and reads. For interaction flows — settings, forms, preferences, empty states, and save/confirm behavior — use `ux-design`.

## Contents

- `SKILL.md` — core instructions loaded when the skill activates

## Install

Place the `ui-design-craft` directory in a skills-compatible location for your agent/client. The folder name must remain `ui-design-craft` because the Agent Skills specification requires the directory name to match the `name` field in `SKILL.md`.
