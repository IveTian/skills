# 05 · 信息架构与页面模式

把这些模式当默认答案；新应用把「Agent / 会话」替换成自己的主对象 / 子对象即可。

## 侧栏即导航

自上而下：

1. **Workspace 选择器**（对照 Linear）：工作区徽标 22px + 名称，点开 Menu：
   - 设置 · 邀请和管理成员
   - 切换 Workspace ▸（子菜单：当前邮箱、我的 Workspace 单选、收到的邀请、新建 Workspace）
   - 退出登录
   账户操作只在这里，侧栏底部不放账户区。
2. **主动作**（`SidebarItem tone="primary"`）：新建（⌘N）、搜索（⌘K，打开命令面板）、活动 / 收件箱。
3. **分组列表**（`SidebarSection`，可折叠，标题右侧可放「+」）：**按状态组织**，例如「需要处理 → 运行中 / 已排程 → 我的对象（可展开子项）→ 已归档」。只在有数据时出现的分组不要占位。
4. 行：紧凑 28px，行尾放元信息（计数、相对时间、状态点）；可展开的对象用 `SidebarTreeItem`。
5. 右键菜单：在新标签页中打开、新建子项、归档 / 取消归档、删除（确认）。
6. 空状态：12px 弱色一句话（`.sidebar-empty`）。

侧栏上任何悬停 / 选中 / 按下 / 菜单展开中的状态都用 `--chrome-*` 半透明叠加色。

## 输入框为起点（空状态）

「新建」页 = 居中的大输入框（Composer），宽不超过 720：

- 上方：上下文选择（如「交给：新对象 / 已有对象」），用 chip 按钮 + Menu。
- 下方：模板提示（卡片按钮）。
- 一个输入框既创建也使用：选「新对象」→ 以描述创建草稿；选已有对象 → 直接开始一次使用。
- 能力暂不可用时，发送按钮禁用并**说明原因**，不要静默失败。

## 命令面板 ⌘K

`CommandPalette`：搜索框 48px、分组结果、32px 选项、底栏 36px 显示键位提示；点击与回车都执行；包含导航（打开对象）、动作（新建、切换侧栏）、设置入口。

## 详情页 + 右侧属性栏

主区域是内容（对话 / 文档 / 列表），右侧是「档案」栏（宽 320，开合与左侧栏同一过渡，⇧⌘\ 切换；窄窗口改 Drawer）：

- 由多张 `SideCard` 组成，卡片间距 8、距面板右缘 8；每张卡片标题行可折叠，内容为 `PropertyRow`（标签列 90，12px 次要色；值 12px）。
- 用「几个问题」组织，而不是一堆设置页。原项目的五问：它做什么 / 能访问什么 / 正在做什么 / 结果在哪 / 怎么改或停。未开放能力如实标注。
- 面板顶栏：左侧面包屑（胶囊按钮），中间 `SegmentedControl` 切换模式（如「对话 | 调整」），右侧「更多」Menu 与右侧栏开关。

## 列表与活动页

- 内容宽不超过 820 居中；行为卡片按钮或列表项按钮；行尾 `RelativeTime` 与 `Tag`。
- 加载 / 空 / 错误统一用 `LoadingState / EmptyState / ErrorState`，错误带重试。

## 设置页（对照 Linear 设置页实测）

设置是**独立的全窗口页面**（隐藏窗口框架但保持挂载），左侧设置导航 + 右侧内容。参考实现 `assets/desktop-shell/renderer/settings-parts.tsx` 与 `shell.css`「设置页」一节。

| 部位 | 规格 |
| --- | --- |
| 设置导航 | 宽 230；顶部「‹ 返回」；分组名与条目同为 13 / 500 次要色；条目 28 高、圆角 8；图标一律实心；分组不可折叠；不做设置搜索 |
| 单栏页面 | 内容宽 640 居中；标题 24 / 32、500、字距 -0.16px，距顶 64；标题 → 首个分组 32；分组标题 15 / 500 → 卡片 16；卡片 → 下一分组 48；同组卡片间 10 |
| 卡片 | 白底、圆角 10、无边框：`0 0 0 0.5px` 半透明描边阴影 + 两层极淡投影 |
| 行 | 最小 60 高、内边距 16、间距 12；行间 0.5px 分隔线左右内缩 16；名称 13 / 500，说明 12 / 450 次要色，数值 13 次要色 |
| 选择框 | 30 高、圆角 8、右侧 10×5 小箭头、13 / 400；由 `Menu + MenuRadioItem(closeOnClick)` 组合（`SettingsSelect`），选项可带 `leading` 预览；最宽 280 |
| 行内输入框 | 宽 256、高 32；**失焦或回车即保存，没有单独的保存按钮**，保存后 Toast「已保存」 |
| 按钮 | 32 高胶囊；「管理」类为文字按钮 |
| 列表卡片 | 首行「N 个 xx」+ 右侧操作；列表行首 32 图标方块 |
| 入口卡片 | 图标 + 标题 + 说明 + 右箭头，整张可点击（Button `card` 变体） |
| 全宽页（成员、用量明细） | 左右约 56 内边距；搜索 300 宽 + 筛选，右侧主操作；表头 32 高 12px；成员行 50 高、头像 24；角色徽标 12px 浅底、圆角 3 |
| 用量图表 | 指标行（数值 24 / 500 + 13 标签）+ 时间范围胶囊；手写 SVG 柱状图 / 热力图，细标记、虚线网格、右侧刻度，颜色只用 `--viz-*` |

建议的设置分区：**账户**（偏好设置 / 主题编辑器 / 个人资料 / 安全与访问：当前设备卡片 + 其他设备列表「全部退出」）；**管理**（仅管理员：Workspace / 成员 / 主题编辑器 / 集成或供应商 / 账单 / 用量与限额 → 用量明细）。普通成员只看到自己有权限的部分。

## 主题编辑器

参考实现 `assets/theme/theme-model.ts`（合约 + OKLCH 推导）与 `apply-theme.ts`（Renderer 应用）。

- 界面主题选择框：跟随系统 / 浅色 / 深色 / 自定义 /（Workspace 主题）；选项左侧「Aa」样张显示该主题的背景、文字与强调色。跟随系统时再显示「浅色外观用…」「深色外观用…」两行。
- 自定义主题**只有三项**：强调色、背景色（`#RRGGBB` 小写）、按钮圆角（0 / 4 / 6 / 8 / 10 / 12 / 胶囊），右上角「恢复默认」。
- 推导（OKLab / OKLCH）：
  - 背景 oklch 亮度 L < 0.6 → 深色主题（文字、边框沿用深色变量）；
  - 内容区 `--surface-canvas` = 背景色；外层 `--surface-window` / `--ground` = 同色相、亮度 −0.035（深色 −0.03）；卡片 / 浮层 `--surface` 比内容区稍亮；
  - 强调悬停：浅色主题变暗、深色变亮 0.06；浅底与强调文字按深浅取固定亮度；按钮文字按强调色亮度在白 / 深灰之间选；
  - 圆角写入 `--button-radius` / `--button-radius-lg`。
- 应用：内联样式写到 `<html>`、`data-theme="custom"`；深浅交给 Main 的 `nativeTheme.themeSource`；生效主题缓存到 `localStorage` 供下次首帧前应用，注销时清除。
- Workspace 主题：管理员可设并「强制所有成员使用」；强制时成员的主题编辑器只读并说明原因（服务端同样拒绝修改）。
