# 01 · 视觉语言

基准：Linear（浅色主题）。所有数值是在 Linear 网页 / 桌面版读取计算样式实测得到的，再映射为设计变量。深色模式按同一层次单独选色，不是自动反转。

## 原则

1. **克制**：灰阶为主，强调色只用于主操作、发送、选中。状态色（成功 / 注意 / 危险）只在需要时出现。
2. **两层表面**：实色窗口底承载侧栏，内容放在一块浮起的圆角面板里；面板内的卡片 / 输入框 / 浮层更亮一级。
3. **细线 + 极淡阴影**：层次靠 0.5px 线与 2%–4% 的阴影，而不是粗描边或重投影。
4. **紧凑密度**：13px 主字号、28px 行高的侧栏、32px 的菜单项，像生产力工具而不是营销页。
5. **桌面习惯优先**：原生菜单栏与快捷键、右键菜单、⌘K、前进 / 后退、标签页、记住窗口位置。

**半透明叠加色**（叠在任意底色上，侧栏与标签栏必须用它）：

| 状态 | 浅色 | 深色 | 变量 |
| --- | --- | --- | --- |
| 悬停 | 黑 3.5% | 白 4% | `--fill-translucent-hover` → `--chrome-hover` |
| 选中 | 黑 6% | 白 8% | `--fill-translucent-selected` → `--chrome-selected` |
| 按下 | 黑 8% | 白 10% | `--fill-translucent-active` → `--chrome-active` |

在 `#efeff0` 上，3.5% / 6% 黑约等于 Linear 的实色 `#e7e7e8` / `#e1e1e2`。用叠加色的好处：日后改 `--chrome` 不需要逐个改状态色，自定义主题也自然成立。

**数据可视化**：类别色固定顺序（`--viz-series-1` 蓝、`--viz-series-2` 橙）；热力图单一色相四级（`--viz-seq-1…4`，深色模式量越大越亮）。图表手写 SVG，颜色只用 `--viz-*`，文字用文字色。

## 线与阴影

- 细线统一 `--border-width: 0.5px`（Retina 上 1 物理像素；1 倍屏取整为 1px）。1px CSS 线在 Retina 上是 2 物理像素，显得笨重。
- `--shadow-raised`（面板、输入框、提示）：`0 3px 6px -2px 黑2%, 0 1px 1px 黑4%`
- `--shadow-popup`（菜单、通知）：`0 6px 18px 黑2%, 0 3px 9px 黑4%, 0 1px 1px 黑4%`
- `--shadow-dialog`：`0 24px 48px 黑12%, 0 1px 1px 黑4%`
- `--shadow-spotlight`（命令面板）：`0 24px 64px 黑20%, 0 1px 1px 黑4%`
- 「无边框卡片」：`box-shadow: 0 0 0 0.5px var(--border-translucent), var(--shadow-raised)`（设置页卡片）。

## 动效

| 用途 | 时长 | 说明 |
| --- | --- | --- |
| 悬停出现 | 0ms | `:hover { transition-duration: 0 }` |
| 悬停消失 | 150ms | 基础 `transition` 时长 |
| 快速（按下、颜色） | 100ms | |
| 常规（浮层进出、标签让位） | 250ms | 浮层从 `scale(0.96)` 进场，菜单按弹出方向 ±4px 位移 |

| 加载转圈 | 0.8s | |

`prefers-reduced-motion: reduce` 下所有过渡与动画时长归零（全局规则）。
