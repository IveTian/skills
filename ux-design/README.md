# ux-design

An Agent Skill for product interaction design — settings, forms, preferences, empty states, and save/confirm flows — grounded in live Linear and Plane patterns.

Use when designing or reviewing product UX, or when an agent-built UI dumps inputs with a bottom Save button.

## Contents

- `SKILL.md` — core instructions loaded when the skill activates

## Install

Place the `ux-design` directory in a skills-compatible location for your agent/client. The folder name must remain `ux-design` because the Agent Skills specification requires the directory name to match the `name` field in `SKILL.md`.
